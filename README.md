## 🚀 Cara Menjalankan
```bash
git clone https://github.com/habi-labs/Keobi_Aplikasi_Catatan_Keuangan.git
cd Keobi_Aplikasi_Catatan_Keuangan
npm install
npx expo start
```
Scan QR code dengan Expo Go, atau jalankan di emulator Android/iOS.

## 📦 Build
```bash
npx eas build --platform android
```
